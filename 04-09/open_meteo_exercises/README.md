# Open Meteo Exercise

This is a simple exercise to get you started with the Open Meteo API. The goal is to create a Python script that allows the user to search for a city and retrieve the current weather information for that city.

## Docker Build & Run

To build and run the Docker container, use the following commands:

```bash
docker build -t open_meteo_exercises .
docker run -it --rm open_meteo_exercises
```
